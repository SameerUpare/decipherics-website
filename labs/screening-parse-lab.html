    Thresholds and weights
    Placeholders. Drag them to see decisions move. Changes apply to the message in the Screening pages.
    
        
    
        
    
        
    Weights: jw .45, lev .20, tok .10, embed .25, dob .05, country .03, id .07. Absent features are left out of the average; a mismatch counts as zero.
    
    
    
  
    
  
    
    
    Penalties
    Small deductions for scores that depended on an extra form of the name. All values are placeholders.
    
        
        
    
        
    
        
        
    
        
    With the box ticked, "Ali Muhammad" is also compared as "muhammad ali". Name order is only tried on the query side, because a swap is symmetric. Particles such as bin and al stay attached to the name that follows them. Names with more than five parts are not expanded.
    
        
    With the box ticked, "Global Goods B.V." is also compared as "global goods". A score that depended on a core form is reduced by the penalty. Untick it to see the score without this step. Placeholder values.
